Deploy LingoBrain lên VPS

Chạy LingoBrain (Node.js + PostgreSQL) trên VPS đang chạy BookSnap, dùng chung Caddy. Bắt đầu khi code đã push lên GitHub. Bộ từ + audio tự tạo lại từ repo, không cần lấy dữ liệu từ Nhân Hòa. Làm lần lượt chương 2 → 4, mất khoảng 15–20 phút.

Thông số của bạn

Điền vào đây, các lệnh bên dưới tự cập nhật (tô vàng). Chỉ lưu trong trình duyệt này.

Nhãn trên mỗi khối lệnh WINDOWS máy tính của bạn · SERVER phiên ssh vps, user deploy · FILE nội dung một file. Mỗi khối lệnh: bấm Copy, dán nguyên khối (dán thiếu dòng đầu là nguồn lỗi hay gặp nhất).
Điều kiện trước Đã làm xong chương 1–5 của hướng dẫn VPS BookSnap: SSH bằng key (ssh vps), firewall, Docker, DuckDNS, Caddy dùng chung + mạng web, thư mục /srv/apps thuộc user deploy.

1Repo đã sẵn sàng

Repo đã có sẵn các file deploy, không phải tạo gì trên server:

FileVai trò
DockerfileNode 22 alpine, chạy bằng user node, HEALTHCHECK gọi /

Kiểm traTrang GitHub của repo phải thấy compose.yml và thư mục deploy/. Chưa thấy = chưa push.

2Clone code + file bí mật .env

Chạy bằng user deployDấu nhắc phải là deploy@…$, không phải root@…#. Đang root thì gõ su - deploy trước. Chạy bằng root → file thuộc root → chmod: Operation not permitted, deploy.sh/cron backup lỗi quyền.
Server
cd /srv/apps
git clone --depth 1  lingobrain
cd /srv/apps/lingobrain
git log --oneline -1
ls Dockerfile compose.yml deploy/
[ -f .env ] || printf 'DB_PASSWORD=%s\n' "$(openssl rand -hex 24)" > .env
chmod 600 .env
ls -l .env
mkdir -p /srv/backups/lingobrain
  • git clone in Cloning into 'lingobrain'... rồi Updating files … done. Repo có ~180 MB MP3, mất 1–2 phút.
  • git log in mã commit mới nhất trên GitHub. ls in đủ Dockerfile compose.yml + backup.sh deploy.sh.
  • [ -f .env ] ||: chỉ tạo .env khi chưa có. Postgres chỉ nhận mật khẩu ở lần tạo DB đầu tiên → ghi đè .env sau đó làm app mất kết nối DB.
  • ls -l .env phải là -rw------- 1 deploy deploy. Chủ là root = đã chạy nhầm bằng root → làm lại bên dưới.
  • Muốn đổi giọng/giới hạn TTS: thêm TTS_VOICE=…, TTS_DAILY_MAX=… vào .env.

Làm lại từ đầu (clone lỗi / lỡ chạy bằng root)

ls -la lingobrain
docker volume ls | grep lingobrain

Chỉ xoá khi docker volume ls không in gì (chưa có DB) hoặc DB chưa có dữ liệu thật:

  • Xoá xong chạy lại nguyên khối lệnh đầu chương 2.

3Chạy app

Server
cd /srv/apps/lingobrain
bash deploy/deploy.sh
docker compose ps
docker compose logs --tail 30 app
  • Script tự bật DB, build image, chạy app, đợi app sẵn sàng. Lần đầu build 1–3 phút. Kết thúc bằng deploy ok: <commit>.
  • Log app: listening on :3000 → schema ready → deck seeded: 5033 words, 10065 audio (+5033 ~0 -0). Lần deploy sau là deck up to date.
  • ps: app và db đều Up … (healthy).
  • Báo deploy FAILED: đọc 60 dòng log script in ra, tra chương 8.

Tài khoản chủ (tuỳ chọn)

Server
cd /srv/apps/lingobrain
docker compose exec -e ADMIN_USERNAME=ten-tai-khoan app sh -c 'read -rs ADMIN_PASSWORD; export ADMIN_PASSWORD; node tools/seed-database.js --skip-deck'
  • Gõ mật khẩu (không hiện) rồi Enter. Hoặc bỏ qua, đăng ký thẳng trong app như người dùng thường.
  • Đã có tài khoản đó, muốn đổi mật khẩu: thêm --reset-owner-password sau --skip-deck.

4Gắn tên miền + kiểm tra

Server
cat > /srv/caddy/conf/sites/lingobrain.caddy <<'EOF'
. {
	encode zstd gzip
	reverse_proxy lingobrain:3000
}
EOF
cd /srv/caddy
docker compose exec caddy caddy validate --config /etc/caddy/Caddyfile
docker compose exec -w /etc/caddy caddy caddy reload
  • encode: /api/words ~2,6 MB → nén còn vài trăm KB.
  • DuckDNS tự trỏ mọi tên con về IP, không cần tạo thêm. validate phải in Valid configuration.
Windows
curl.exe -sI https://./
curl.exe -s -o NUL -w "%{http_code} %{size_download}\n" -H "Accept-Encoding: gzip" https://./api/words
curl.exe -s -o NUL -w "%{http_code}\n" https://./package.json
  • Lệnh 1: 200, có Strict-Transport-Security + Content-Security-Policy.
  • Lệnh 2: 200, kích thước nhỏ hơn nhiều so với 2,6 MB (đã nén).
  • Lệnh 3: 404 (file hệ thống không bị lộ).
Server
sudo ss -tlnp | grep -v 127.0.0.

Chỉ thấy 22, 80, 443. Thấy 3000 hoặc 5432 = có cổng lọt ra ngoài.

  • Mở https://. → có ổ khoá, đăng ký tài khoản được.
  • iPhone Safari: Thêm vào màn hình chính → tắt mạng, mở lại vẫn chạy.
  • Ôn 1 thẻ trên máy A, mở máy B cùng tài khoản → thấy thay đổi.

5Người dùng cũ

Tiến độ trên máy (localStorage, PWA đã cài) gắn với tên miền. Server mới không có tài khoản cũ.

Giữ tên miền cũ (trỏ DNS về VPS)Tên miền mới (DuckDNS)
Người dùng làm gìĐăng ký lại đúng tên cũ → tiến độ còn trên máy tự gộp lên server mớiWeb cũ: tab Tôi → Tải backup → web mới: đăng ký → Khôi phục (gộp, không ghi đè)
PWA đã càiGiữ nguyên, tự lên bản mớiCài lại từ tên miền mới
Bản ghi âm shadowingGiữ nguyênMất (không nằm trong backup)
Điều kiệnBạn quản lý DNS của tên miền đóKhông cần gì

Giữ tên miền cũ: ở chương 4 thay . bằng tên miền cũ, hạ TTL xuống 300 giây trước 1 ngày, rồi đổi bản ghi A sang . Caddy tự xin chứng chỉ khi DNS trỏ đúng (có thể mất vài phút).

Dọn Nhân HòaGiữ bản Nhân Hòa ≥ 7 ngày để người dùng kịp Tải backup, sau đó xoá hẳn DB ở đó — nó vẫn giữ hash mật khẩu người dùng và mật khẩu sa từng lộ qua chat.

APhụ lục: chuyển tài khoản cũ từ Nhân Hòa (tuỳ chọn)

Chỉ cần khi muốn giữ tài khoản + tiến độ trên server Nhân Hòa. Không làm thì bỏ qua.

Ghi đè toàn bộ DB trên VPSTài khoản đã đăng ký trên VPS sẽ mất. Làm càng sớm càng tốt, trước khi báo người dùng dùng server mới.
  1. Trên Nhân Hòa: SELECT version(); và SELECT count(*) FROM users; — ghi lại. Bản ≥ 18 → đổi image db trong compose.yml ở repo cho khớp trước.
  2. Lấy file dump: panel Nhân Hòa → Database → Backup → tải về (.dump hoặc .sql.gz).
  3. Đưa lên VPS:
Windows
scp D:\backup\lingobrain\ten-file-backup vps:/srv/backups/lingobrain/

Nạp vào — file .dump:

Server
cd /srv/apps/lingobrain
docker compose stop app
docker compose exec -T db pg_restore -U lingo -d lingobrain --no-owner --no-acl --clean --if-exists --exit-on-error \
  < /srv/backups/lingobrain/nhanhoa.dump
docker compose start app

Hoặc file .sql / .sql.gz (xoá DB rồi nạp lại từ đầu):

Server
cd /srv/apps/lingobrain
docker compose down -v
docker compose up -d --wait db
gunzip -cf /srv/backups/lingobrain/nhanhoa.sql.gz \
  | grep -vE '^(ALTER .* OWNER TO|GRANT |REVOKE )' \
  | docker compose exec -T db psql -U lingo -d lingobrain -v ON_ERROR_STOP=1 -q
FORCE=1 bash deploy/deploy.sh

Kiểm tra: docker compose exec db psql -U lingo -d lingobrain -c "select count(*) from users" bằng số ghi ở bước 1. Nạp xong xoá file dump trên Windows (chứa hash mật khẩu).
