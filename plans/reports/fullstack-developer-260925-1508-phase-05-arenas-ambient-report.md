## Tile coordinate measurement
No canvas/pngjs available (sandboxed, no `node_modules` reads). Wrote a from-scratch PNG decoder in scratchpad (`pngdecode.js`/`pngdecode2.js` — IHDR + zlib `inflateSync` + per-scanline unfilter, extended with `PLTE`/`tRNS` for `dungeon.png` which is indexed-color) plus a "largest all-opaque-non-near-white rectangle" scan (histogram/stack algorithm) per new tileset, at half resolution for speed then ×2 back to full px. This directly targets the documented lesson in `boss-game-arena.js` (autotile round blocks have **opaque white** fill at the bounding-box corners, not transparency) by construction: any crop entirely inside a "safe rectangle" cannot include that white fill, since the rectangle-finder explicitly excludes near-white opaque pixels as blockers. Cross-checked visually with the Read tool (rendered each source tileset once) before picking final crop coordinates, with a small inward margin for safety. All picked tuples are additionally asserted against real PNG IHDR bounds by the new test.

## Design notes / deviations from the illustrative phase-file examples
- `near` field (mentioned in the phase's Architecture sketch) was folded into `far`/`details`/`anim` — the existing `far` mechanism (repeating tuples along the horizon) already covers "extra decorative row," and `anim` covers fixed-position animated tiles; adding a third parallel array wasn't needed and would have duplicated the same rendering path.
- Illustrative examples used monster-specific effect names not in the phase's own **Requirements** kind list (e.g. "RockGray" for troll, "purple light" for lich). The Requirements section explicitly enumerates `leaf, leafPink, snow, rain, ember, fog, clouds` as the implemented kinds — I followed that as authoritative and gave troll/lich a `fog` (dust/haze) ambient instead, still satisfying "≥1 moving element per arena."
- `light: 'raylight'|'clouds'` is implemented as 1–2 *extra* front-layer bands layered on top of the primary `ambient.kind` (not a replacement), so e.g. harpy gets both falling `snow` and drifting `clouds`.
- Every one of the 12 monsters got a distinct `ambient.kind`/override combo; new tilesets (`tileField`, `tileDungeon`, `tileRelief`, `tileDesert`, `tileTowers`, `tileWater`) are each used by at least one arena's `far`, and `tileFloorDetail` by troll's `details`.
